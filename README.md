# kylemccool.com

Personal site for Kyle McCool. Co-Founder of Makko AI, Phantomline, and ProLocalBuilder. Based in Appleton, Wisconsin.

Live: https://kylemccool.com

## Stack

Plain HTML and CSS. No build step, no frameworks. Loads in under 50KB.

## Deploy

Connected to Vercel. Every push to `main` auto-deploys in about 30 seconds.

## Local preview

Open `index.html` in a browser. That's it.

## Files

- `index.html` — the page
- `styles.css` — styles
- `robots.txt` — crawler rules
- `sitemap.xml` — search engine discovery
- `vercel.json` — deploy config and security headers
